# Analisis Komparatif Platform Web, Desktop, dan Mobile

## 1. Tabel Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript | Java, C#, C++, Python | Kotlin, Java, Swift, Dart |
| Arsitektur | Umumnya client-server dan diakses melalui browser | Berjalan sebagai aplikasi pada sistem operasi komputer | Berjalan pada sistem operasi smartphone atau tablet |
| Cara distribusi | Diakses melalui browser menggunakan URL | Diinstal melalui installer atau toko aplikasi | Diunduh melalui Google Play Store atau Apple App Store |
| Keunggulan | Mudah diakses, tidak selalu perlu instalasi, pembaruan terpusat | Dapat memanfaatkan kemampuan komputer dan mendukung pengolahan data lokal | Praktis dibawa, mendukung layar sentuh, kamera, GPS, dan notifikasi |
| Keterbatasan | Beberapa fitur bergantung pada browser dan koneksi internet | Perlu instalasi dan dapat bergantung pada sistem operasi | Ukuran layar terbatas, menggunakan baterai, dan memiliki perbedaan spesifikasi perangkat |
| Contoh aplikasi | Gmail versi web, Google Docs versi web | Microsoft Word desktop, Visual Studio Code | WhatsApp mobile, Google Maps mobile |
